## Что реализовано

Одностраничный сайт «О себе» на чистой семантической разметке (без CSS - это тема ЛР№2):

- `<header>` - герб Кемерово (`img` с `src`/`alt`/`width`/`height`), имя и подзаголовок.
- `<main>` с двумя `<section>`:
  - «Навыки» - маркированный список (`<ul>`) навыков, полезных в путешествиях.
  - «Проекты» - нумерованный список (`<ol>`) из 4 посещённых стран (Грузия, Турция, Армения, Казахстан).
  - «Обратная связь» - форма: поля «Имя» (`type="text"`), «Email» (`type="email"`), «Сообщение» (`<textarea>`), кнопка отправки. У всех полей - `name` и `placeholder`.
- `<aside>` - «Любимое место» (Кемерово).
- `<footer>` - копирайт и год.

## Файлы

- `index.html` - вся страница (единственный файл в этой лабе).

## Как посмотреть

Открыть `index.html` в браузере - сборка/сервер не нужны.
